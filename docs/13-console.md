# 13 · 运营后台与商家后台

电话客服的两个网页后台，与语音助手首页（`/`）互不相干：

| 后台 | 地址 | 给谁 | 登录 |
|---|---|---|---|
| 运营后台 | `https://<域名>/admin/` | 运营（装网关、开通商家的人） | 运营管理员账号 |
| 商家后台 | `https://<域名>/merchant/` | 诊所、培训机构等商家 | 运营开通的商家账号 |

两个后台用同一套账号体系（`/api/login`），但各自保存登录状态，互不串。

## 运营后台能做什么

| 页面 | 内容 |
|---|---|
| 总览 | 门店数、网关在线数、今日与近 7 天来电、意向分布、系统状态（AI 服务、电话交换、网关开通是否可用、录音存储）、最近通话 |
| 商家 | 全部门店（接入号、归属账号、网关在线、近 7 天来电）。**添加商家**一步完成：开商家账号（初始密码可自动生成）→ 建门店 → 分配接入号 → 开通网关，完成后给出"发给商家"的整段文字和 HT813 要填的全部项 |
| 门店详情 | 资料（含运营字段：接入号、转人工分机、音色、热词表）、网关（HT813 配置与在线状态、开通/撤销）、通话、线索、账号（重置商家密码、删除门店） |
| 网关 | 全部网关的在线状态，以及不是在这里开的其他在线分机（配置文件里的老网关、软电话） |
| 通话记录 / 线索 | 跨门店，可按门店和时间筛选，线索可导出 |
| 管理员 | 在页面上授予、撤销管理员。配置文件里的（`VCA_ADMIN_USER_IDS`）是超级管理员，页面上撤不掉 |

**开通网关不再需要服务器命令行。** 网关账号存在库里（`phone_gateway` 表），VCA 按它生成 FreeSWITCH 的分机文件
（`gateways/vca-gw-<LINE 分机>.xml`），再经事件套接字 `reloadxml`，不重启、不影响在途通话：

- 分机号 8NN1 / 8NN2，自动避开库里已有的和 FreeSWITCH 目录里已存在的（老网关 8001/8002、`add-gateway.sh` 开的、软电话）。
- 写库 → 写文件 → 重载，后两步任一失败就撤回前面的，不留"页面上有、注册不上"的半截网关。
- 门店没配转人工分机的，开通时自动配成这台网关的 PHONE 口；撤销网关时一并清掉。
- 门店改了接入号或店名，分机文件跟着重写；门店被删，网关一并撤销。
- 每次启动按库重写全部分机文件（容器重建、文件被误删都能自愈），只动 `vca-gw-*` 前缀的文件。

## 商家后台能做什么

| 页面 | 内容 |
|---|---|
| 概览 | 线路状态（AI 在接听 / 网关不在线 / 还没开通 / AI 已关闭）、今日与近 7 天来电、高意向客户、留资、近 30 天来电柱状图、意向分布、最新线索 |
| 门店资料 | 按行业显示字段叫法；开场白、营业信息、服务与价格、预约规则、语气与禁忌、小结推送群；接入号与转人工分机只读。可预览 AI 实际拿到的资料和开场白（含自动补的告知） |
| 知识库 | 上传 txt / md / pdf，AI 回答时检索 |
| 通话记录 / 线索 | 带 AI 小结和录音回放；线索可导出 |
| 账号 | 改密码（要原密码）、退出。忘记密码由运营在后台重置 |

## 接口

- 运营：`/api/admin/**`（`AdminRoutes`），只给运营管理员。
- 门店资料、单店的通话/线索/录音/统计/线路状态：`/api/merchants/**`（`MerchantRoutes`），门店所属账号或管理员可用。
- 改密码：`POST /api/password/change {oldPassword,newPassword}`。

页面里的门店资料、通话摘要、客户原话一律按纯文本渲染（不拼 HTML）。录音回放用 fetch 带令牌取回再播放，没有"凭链接就能听"的口子。

## 服务器上一次性的设置

```bash
# 1. VCA 要能写网关分机目录(目录由 FreeSWITCH 容器创建, 属主是 root)
chown vca /opt/vca/freeswitch/gateways

# 2. /etc/vca.env 加三行, 然后 systemctl restart vca
VCA_FS_GATEWAYS_DIR=/opt/vca/freeswitch/gateways
VCA_FS_ESL_PASSWORD=<与 /opt/vca/freeswitch/.env 的 ESL_PASSWORD 一致>
VCA_FS_SIP_SERVER=<服务器公网 IP>
```

启动日志里出现 `运营后台: 网关分机目录 …, 事件套接字 127.0.0.1:8021` 与 `网关分机已同步: N 台` 即就绪；
总览页的"网页开通网关"显示"可用"。
